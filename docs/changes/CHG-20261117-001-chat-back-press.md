# CHG-20261117-001 聊天页顶栏按压样式

- 日期：2026-11-17（北京时间）
- 状态：已发布，已验收
- 需求来源：用户要求调整返回按钮和未读数所在区域的椭圆按压背景，并先看截图。随后要求统一其余按钮的按压颜色和圆形尺寸。

## 为什么改

返回按钮预留了未读数位置，原先的 50% 圆角在宽扁按钮上呈椭圆。

## 改了什么

顶栏五个按钮按下时使用原先搜索及右侧按钮的浅灰背景（5% 黑色）。返回键的胶囊高 32 像素，右端圆弧与未读圆标同心。搜索、整理今日记忆、多选和进入记忆页按钮使用直径 32 像素的圆形背景。

## 影响与兼容

涉及聊天页按钮 CSS。接口、存储、权限及数据迁移不适用。

## 验收与结果

本地 Chromium 在 375 像素宽度下逐个按住五个按钮，验证背景色一致、胶囊尺寸为 64 × 32 像素、其余四个圆形背景均为 32 × 32 像素，并截取对照图。线上安装文件哈希、隔离单聊及群聊模板、公网登录和三语指南验收均通过。

## 使用文档与更新日志

已更新中、日、英三版指南的聊天章节（#chat）及 CHANGELOG.md 未发布条目。

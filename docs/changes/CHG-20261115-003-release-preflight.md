# CHG-20261115-003 · 发布前检查

- 状态：仓库流程变更，安装器和新站应用均沿用现行版本。
- 范围：A12 的常规发布前检查。

过去离线回归和生产基线核对分布在各个发布批次。现在从项目根运行 `.venv/bin/python deploy/check-release.py <manifest.json> <files目录>`，先验证包内文件和清单完全一致，跑现有离线核心回归，再通过只读 SSH 对比生产摘要。新文件的 `before` 使用 `null`，源包 SHA-256 使用 `after`。已安装批次可用 `--installed` 对照 `after`，便于核对实际安装结果。

文件缺失、额外文件、符号链接、摘要变化、测试失败或 SSH 无法完成时返回非零退出码。命令只读取线上允许范围内的文件摘要。实际安装仍由批次安装器完成，并在落盘前复核基线。已有 Agent 专项测试由涉及 Agent 的批次另行运行。核心回归新增此次已验收的并发保存与聊天历史测试。

三语用户指南不适用，本变更仅影响维护者发布流程。用法见 [项目协作规范](../../CONTRIBUTING.md#6-发布与线上验收)，并已加入更新日志。

## 验收

用已经上线的 A14 发布包实际运行 `--installed`。159 项核心测试、32 项子测试及额外 2 项安全测试通过，包内及线上 8 个文件的 SHA-256 全部匹配。另用合成清单验证意外文件、包内文件变化和生产基线变化均会阻断。默认沙箱限制本机 TLS 用例所需的套接字，实际验收在获得执行许可后通过；测试仍使用隔离业务数据。此次只读核对线上文件，未触发发布。

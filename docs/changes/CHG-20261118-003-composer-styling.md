## 为什么改

提示词下拉框接近浏览器默认外观。用户要求轻微美化，并进一步明确保留转账黄色、原有白色背景，仅在选中/聚焦时显示粉色边框、下拉框使用圆角。

## 改了什么

共享 `static/composer-surfaces.css` 只设置提示词下拉框的12px圆角及中性边框、输入框聚焦时的淡粉边框和轻微光圈，以及AI识图模式选中的粉色边框。下拉框保留白底和原生箭头。

已撤回第一版过度美化：不覆盖弹窗、标题、按钮和转账金额原有颜色，不添加粉色底板、粉色渐变、装饰图标或全局胶囊按钮。转账保持原黄色，弹窗保持原白色。三语指南与更新日志按最终实际样式重写。

不修改业务规则、提示词存储或发送与取消逻辑；沿用原有弹窗滚动与视口适配。无迁移、权限或凭据变化，无需ADR。

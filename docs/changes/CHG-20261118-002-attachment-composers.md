# CHG-20261118-002：转账编辑与识图提示词复用

- 日期：2026-11-18（Asia/Shanghai）
- 状态：已发布、已验收
- 范围：用户提出四项需求：扩展面板发送转账、领取/退回转账附加文字、聊天识图提示词保存复用、朋友圈共用识图提示词及弹窗遮挡修复。本轮本地实现，不沿用上一批模型变更的发布授权。

## 为什么改

此前只能手写转账标签；领取/退回只能发送操作标签，不能附加留言。聊天识图提示词每次都要重填，朋友圈缺少同等设置。朋友圈弹窗 z-index 为20，低于底部导航999，操作区可能被遮挡；移动端软键盘也会缩小可用区域。

## 改了什么

| 场景 | 变化 |
|---|---|
| 单聊和群聊扩展面板 | 新增转账入口，填写金额、币种、备注及附加文字。六个入口一行排列，增加面板高度和滚动以容纳换行标签 |
| 发送转账 | 金额正数、最多两位小数、上限999999999.99；币种为1–12个字母或货币符号；备注不超过80字且不能包含标签/斜杠分隔符和换行。沿用既有虚拟转账标签和消息保存/生成两阶段链路 |
| 领取与退回 | 附加文字和操作标签一起保存；保留来源ID、来源角色、金额及币种一致性、重复操作校验，拒绝同消息多个决策或缺少来源的伪造决策。单聊和群聊共用规则 |
| 转账编辑 | 带入聊天草稿，提供与图片编辑相同的翻译与替换确认，支持斜杠分气泡，卡片在最后；取消保留主输入框草稿，成功保存后才清理原草稿，失败保留弹窗文字 |
| 提示词保存 | 新增账号独立的保存、选择、删除；最多30条、每条2000字，去重；聊天和朋友圈共用。保存立即生效，取消图片发送不撤销已保存或删除的提示词 |
| 朋友圈图片 | 本条朋友圈一个识图提示词，应用于所有AI模式图片；手动描述忽略，全部手动时输入区隐藏，留空使用原默认要求。不把提示词写入正文 |
| 朋友圈发布失败 | 保留草稿、图片和提示词；AI失败只将失败图片改为手动，其他AI图片仍使用共用提示词。发布成功或明确取消后清空本次提示词，保留已保存项 |
| 弹窗 | 提升朋友圈遮罩至导航栏上方，保留可滚动内容，操作区使用吸底样式；图片、转账和朋友圈弹窗适配 visualViewport 的高度和偏移；转账弹窗包含焦点圈定及Escape取消 |

## 影响与兼容

- `templates/chat.html`、`templates/moments.html` 及独立前端编辑器模块；原图片发送、手动描述、转账卡片渲染和旧客户端继续使用。
- `blueprints/chat.py` 允许单个转账决策标签前后携带文字，仍在原SQLite事务中更新来源卡片和保存用户消息。
- `blueprints/moments.py` 接收可选 `vision_prompt`，AI图片处理前校验；无参数沿用原调用，手动描述不调用识图模型。
- `POST/GET /api/vision/prompts` 要求登录；保存到当前账号 `configs/vision_prompts.json`。按文件加锁并原子保存，使用增删操作避免不同窗口互相覆盖。不读取其他账号、不迁移旧数据、不修改凭据。
- 重要规则沿用既有协议，新增存储和边界已在本记录明确，无需另立ADR。

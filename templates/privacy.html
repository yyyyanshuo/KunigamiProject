本政策说明 Kunigami 在公开测试阶段如何处理个人信息。请特别关注第三方 AI、语音服务及跨境处理相关说明。

Kunigami 重视你的个人信息与隐私。本政策适用于你访问、注册和使用 Kunigami 网站、PWA 及相关功能的过程。

一、我们处理的信息

1. 账号与资料

包括邮箱、显示名称、密码哈希、头像、年龄确认状态、语言、时区、通知设置和账号创建时间。

2. 用户创建和交互内容

包括角色设定、聊天记录、记忆、群聊、动态、评论、广场投稿、上传的图片或音频，以及你主动提供的其他内容。

3. 第三方服务配置

包括你主动保存的 Gemini、OpenRouter、ElevenLabs 等 API Key 及相关配置状态。完整 Key 采用加密方式保存，页面原则上不回显完整内容。

4. 使用、安全与故障信息

包括登录会话、设备账号记录、接口错误码、模型线路状态、Token 使用量、安全审计记录、网络日志以及为排查故障所需的时间和操作信息。

二、处理目的

  • 创建账号、身份验证和维持登录状态；
  • 提供角色聊天、记忆、群聊、广场、语音和通知等功能；
  • 调用用户选择的 AI、语音或中转服务并返回结果；
  • 保存偏好、同步数据、统计资源消耗和改善体验；
  • 保障账号与系统安全，防范滥用并处理投诉、举报和申诉；
  • 履行适用法律法规要求。

三、第三方处理与数据传输

当你选择相应线路或功能时，为完成请求，平台可能向第三方发送必要数据：

  • Gemini / Google：处理文本、图片等模型请求；
  • DeepSeek、OpenRouter 或中转服务：处理模型请求和返回内容；
  • ElevenLabs：处理音色、语音合成或相关媒体请求；
  • 邮件与浏览器推送服务：发送你主动开启的通知；
  • 云服务器、对象存储及网络服务商：提供数据存储、传输和安全防护。

第三方可能位于中国境外。发送的数据可能包含你的输入、必要上下文、角色设定或媒体内容。请勿在提交给第三方模型的内容中填写不必要的身份证号、金融账户、精确住址、健康隐私或他人秘密。

四、保存方式与期限

  • 账号资料通常保存至账号注销或处理目的完成；
  • 角色、聊天、记忆及上传内容保存至你主动删除、账号注销或服务终止；
  • 第三方 API Key 保存至你覆盖、删除或注销账号；
  • 协议确认记录、安全日志及依法需要留存的记录，按照安全需要和法定期限保存；
  • 超过必要期限后，我们会删除或匿名化处理，但法律法规另有要求的除外。

目前主要服务基础设施位于新加坡。正式面向中国大陆商业运营前，数据存储和跨境处理安排可能调整，并会相应更新本政策。

五、Cookie、本地存储与设备记录

我们使用会话 Cookie 维持登录和安全状态，并可能使用本地存储保存界面偏好。设备账号记录用于展示近期在同一设备登录过的账号。禁用必要 Cookie 可能导致无法登录或使用核心功能。

六、你的权利

在适用法律范围内，你可以：

  • 查看和修改账号资料、角色设定与偏好；
  • 删除聊天、角色、上传内容或第三方凭据；
  • 关闭非必要通知或解除第三方功能配置；
  • 通过个人主页注销账号；
  • 联系我们申请查阅、更正、复制或删除相关个人信息；
  • 对个人信息处理提出疑问、投诉或请求说明。

为保护账号安全，我们可能在响应请求前核验你的身份。

七、安全措施

我们采取密码哈希、敏感凭据加密、会话保护、权限隔离、安全日志和备份等合理措施。互联网服务不存在绝对安全；如发现账号或 Key 异常，请立即修改凭据并联系我们。

八、账号注销

你可以在个人主页底部发起注销。注销会删除账号、个人配置、角色、聊天、论坛内容等数据；广场投稿的具体处理以注销页面提示为准。依法必须保留的安全、交易或争议处理记录可能在必要期限内继续保存。

九、未成年人

Kunigami 仅面向已满 18 周岁的用户。我们不会有意向未满 18 周岁的人提供注册服务。发现不符合年龄要求的账号时，可以采取限制或关闭措施。

十、政策更新

功能、第三方服务、运营主体或处理目的发生变化时，我们可能更新本政策。重大变化会通过页面提示等合理方式通知；依法需要重新同意的，我们会再次征求确认。

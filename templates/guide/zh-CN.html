1. 账号开通、登录与找回密码

注册账号（管理员开通）

  1. 发邮件至 yyyyanshuo@foxmail.com 联系管理员，提供能收到邮件的邮箱和想使用的昵称。
  2. 按管理员提供的方式支付 9.9 元人民币的账号开通费。
  3. 管理员开通后会把登录账号和初始密码发给你。用账号邮箱和初始密码登录花期，然后到个人主页修改密码。
  4. 请阅读用户协议与隐私政策，并在个人主页完成确认。花期目前仅面向 18 岁以上用户。

请使用自己能够收信的真实邮箱，并妥善保存密码。通知邮箱与账号邮箱用途不同：找回密码时需要填写账号邮箱。

登录账号

打开登录页面，输入账号邮箱和密码。登录和忘记密码页面均提供“使用文档”按钮，会在新标签页打开本指南。

找回密码

  1. 在登录页点击“忘记密码”，进入找回密码页面。
  2. 填写账号邮箱，点击发送验证码，然后检查收件箱与垃圾邮件文件夹。
  3. 填写邮件中的 6 位验证码和新密码。验证码在 10 分钟内有效；重新发送后请使用最新收到的验证码。
  4. 提交后，页面提示密码重置成功，并返回登录页。使用新密码重新登录；旧登录会话需要重新认证。

发送按钮有约 60 秒的再次发送等待时间。验证码过期时重新获取；持续收不到邮件或无法访问原邮箱时，请联系支持人员。邮件能否送达取决于邮件服务和收件方状态。

2. 配置个人信息

  1. 在个人主页设置头像与显示名称。
  2. 进入账号与通知设置，设置年龄、拍一拍后缀、默认对话语言及其他个人偏好。
  3. 进入全局用户设定 → 编辑，填写你自己的人设，完成后保存。

默认对话语言用于和角色聊天、自己发朋友圈，相当于你世界观中的语言。网站内置翻译，可先把待发送内容译为对应交流语言，再修改并发送。角色或群聊单独设置了交流语言时，会优先使用其设置。

用户语言用于网站界面与阅读译文，可以通过页面语言选择器切换。它可以与你世界观中的语言不同。例如，界面用中文、默认对话语言设为日语时，你可以用中文写草稿，再翻译成日语发送。

不同设置入口同时保存不同选项时，各自的修改会保留。

3. 接收通知

  1. 邮箱通知：进入个人主页 → 账号与通知设置，在“通知邮箱”中填入用于接收通知的邮箱。
  2. 浏览器消息推送：进入个人主页 → 浏览器消息推送，点击“开启通知权限”。推荐使用 Firefox（火狐）浏览器，其他浏览器可能开启失败。
同一设备使用多个账号：请分别登录每个需要接收推送的账号，并在每个账号中单独点击一次“开启通知权限”。同一设备可以同时接收这些已主动开启账号的通知。

4. 配置线路与模型

进入个人主页 → 线路与模型设置 → 配置，按下面的顺序操作。

  1. 选择线路：Gemini、ChatGPT、Claude、Grok 或“自填写”。选择自填写时，还需填入线路名称、HTTPS API 地址和服务商支持的接口格式。
  2. 填写 API Key：填入当前线路对应的 Key。不同服务商的 Key 不能混用；自填写线路须使用对应服务商提供的 Key。已保存的完整 Key 不会回显。
  3. 选择模型：分别为聊天、翻译、识图、人设、语音电话、朋友圈、记忆、生图和论坛选择模型。若列表中没有所需模型，可添加服务商实际支持的模型 ID。
  4. 按需设置每日生图上限，点击保存配置。Key 和模型设置保存后才会生效。

如何选择模型？以 Gemini 为例

同代模型通常可按 Pro → Flash → Flash-Lite 理解：一般越往右，速度与成本更有优势；Pro 更侧重复杂任务和细节表现。这是选型思路，跨代比较仍需看具体能力，不能只按 Pro、Flash 名称排序。

用途建议档位怎么选
聊天Flash默认使用 gemini-3.8-flash，兼顾角色表现和回复效率。
语音电话Pro / Flash追求人设选 Pro；希望回复更快，可选 Flash。这里配置的是通话回复模型，声音另由音色设置控制。
翻译Flash-Lite日常翻译优先轻量模型，例如 gemini-3.5-flash-lite；复杂语境可改用更强档位。
朋友圈推荐 Flash / ProFlash 通常已足够；更追求人设细节时选 Pro。
识图较强的 Pro / Flash比较实际视觉能力。较新的 Flash 可能优于较早的 Pro；本站当前优先推荐 gemini-3.8-flash，不把“3.8 Flash > 3.1 Pro”视为所有任务的固定排名。
记忆推荐 Flash默认使用 gemini-3-flash-preview（Gemini 3.0 Flash，预览版）；可按需要选择其他可用的 Flash。

生图画质优先的生图模型默认生图模型为 gemini-nano-banana-2.1（Nano Banana 2.1）。可在下方限制每天最多生成几张。
论坛较新的 Flash优先兼顾长篇生成与速度，例如 gemini-3.8-flash。

Gemini 4 在本站按选型用途分组：gemini-4-hydrogen 归入 Flash，gemini-4-carbon 和 gemini-4-argon 归入 Pro。这是本站分组，不是 Google 的型号后缀。聊天、通话默认使用 gemini-3.8-flash；记忆默认使用 gemini-3-flash-preview。已保存的模型选择不会自动覆盖；如需应用新默认值，点击对应任务的“恢复推荐值”后保存。Google 已公告 2.5 Pro / Flash 于 2026 年 12 月 1 日退役，详情见官方模型列表与模型生命周期说明。

其他线路同样可以按“聊天与人设重能力、翻译重速度、记忆与论坛重平衡”的思路分配。只有支持图像输入的模型才能用于识图；生图需要专用能力。广场试聊与语音识别使用另行配置的平台服务，不随个人聊天模型一起切换。

5. 新建角色并配置

新建角色或修改备注时，最多可用 10 个全角字符。两个半角字母或数字算一个全角字符，可以混用。已有的长名字可以继续使用。

  1. 在联系人页面点击右上角加号，选择新建联系人。
  2. 填写 ID 和姓名。ID 只能包含英文字母、数字和下划线。
  3. 进入该角色的聊天页面，点击右上角角色设置入口，打开角色记忆页面。
  4. 在角色档案 → 基本信息 → 编辑资料中配置头像、备注名、年龄、拍一拍后缀、角色交流语言，以及是否置顶。
  5. 在核心设定 → 角色人设中编辑人设。你可以直接填写，也可以输入角色名称和所属 IP（作品）后用 AI 生成；还可以复制 AI Prompt，交给自己的 AI 生成，再将结果粘贴回来。
  6. 在核心设定 → 关系图谱中编辑关系。“我的视角”指当前角色对其他角色的看法；“他人视角”指其他角色对当前角色的看法。支持卡片编辑、JSON 编辑和 AI 生成；也可复制 Prompt 给自己的 AI，将返回的 JSON 粘贴到编辑框中覆盖。记得在卡片编辑中补充角色对你的看法。
  7. 可选：在动态记忆 → 近期日程中设置日程。可逐条添加，也可在“高级工具”中切换到源代码模式整体替换；还可复制其他角色的日程，或将当前日程同步给其他角色。

用独占一行的 [[LOCK]] 和 [[/LOCK]] 包住核心设定，例如：

[[LOCK]]

# 可继续调整的补充设定
- 与用户相处时的习惯

角色和模型会读取锁定内容，并在以后由 AI 编辑、重写人设时保留区块内的文字。这不会限制你本人：编辑框仍是普通文本，你可以修改区块内任何文字、移动或删除标签、重新划分范围；保存后以你的新版本为准。

保留标签时，必须成对、独占一行，且不能嵌套。AI 自动生成人设会为明确的官方或原作资料添加保护，将推测、创作补充和互动偏好留在标签外。普通聊天中角色会读取这些内容，不会主动解释标签。

6. 与角色进行聊天

聊天名居中显示在顶部工具栏内，单聊状态在名字正下方。窄屏上，长名字可以延伸到记忆等按钮下方，按钮仍可点击，工具栏保持一行高。点左上角的箭头返回，点旁边的放大镜搜索聊天记录。返回按钮和右侧按钮组距屏幕边缘一样远。箭头和放大镜之间的浅灰半透明圆标只合计其他单聊和群聊的未读消息。当前会话收到新消息时不会增加这个数字。每隔约 3 秒，圆标和角色状态随消息一起刷新。其他会话没有未读消息时圆标隐藏，放大镜始终在同一位置。翻看历史记录时，数字和状态也会更新，页面会保留你正在看的位置。未读数暂时无法获取时，圆标会隐藏，下一次成功刷新后会显示最新数字。按住顶栏按钮时会出现浅灰背景。返回箭头和未读数共用胶囊形背景，其余按钮使用同样高的圆形背景。

  1. 在输入框填写文字，点击发送。
  2. 当用户语言与角色交流语言不同时，输入框上方会出现翻译框；角色未设置语言时，使用默认对话语言。在翻译框输入文字并点击翻译，译文会自动填入发送框，可继续修改后发送。若未修改译文，发送后气泡底部会附上翻译前的原文。
  3. 点击输入框左侧的语音按钮，切换到“按住说话”，长按录音。按提示授予麦克风权限；录音时可上滑取消。
  4. 点击输入框右侧加号，打开扩展面板，选择图片、表情、常用语、转账、语音通话或网站。
  5. 双击角色头像，可以拍一拍角色。
  6. 打开消息操作菜单，可对角色消息进行语音重生成（适用的最后一条消息）、播放、翻译、编辑、删除和复制。翻译入口在用户语言与实际交流语言不同时显示。
  7. 收到角色转账时，可选择领取或退回；这是聊天中的虚拟互动。

扩展面板

  • 图片：选图后可让 AI 识别，也可自行填写描述；支持填写总结要求和随图发送文字，详见发送图片与配文。
  • 表情：在爱心标签使用自己添加的表情，添加时填写描述。通过加号添加表情包，也可上传自己的表情包并公开分享；支持搜索。
  • 常用语：保存常用指令或短句，点击后会追加到输入框末尾，检查后再发送。
  • 语音通话：向当前角色发起电话。
  • 网站：输入网址，让角色读取可访问的网页内容。

发送转账与转账附言

转账、图片和朋友圈编辑弹窗内，识图提示词的字号与朋友圈正文输入框一致。正在编辑的输入框会显示粉色边框，已保存提示词可从圆角下拉框选择；内容超出屏幕时可在窗内滚动。

点击输入框右侧的加号 → 转账，填写金额、币种（如 CNY、USD、JPY 或货币符号）和可选备注，再点击发送。金额必须大于零，最多两位小数，上限为 999999999.99；备注最多80字，不能包含 [ ] | / 或换行。这是聊天中的虚拟互动，不涉及真实支付。

点击角色发来的待处理转账卡片，可以领取或退回。发送、领取和退回转账都可填写附加文字，聊天输入框中的草稿会带入弹窗；用 / 分隔文字气泡，转账卡片放在最后。需要跨语言交流时，可在弹窗内先翻译再修改，确认后再发送。取消不会发送或处理转账，也不会清空聊天草稿；发送失败保留弹窗中的文字。保存成功后才清空原聊天草稿。同一笔转账只能领取或退回一次。

让角色生成图片

在线上模式的单聊或群聊里，可以直接说“发一张你训练结束后坐在场边的自拍”。角色会从自己手机摄像头的视角描述成片。你也可以指定景别、角度和位置，例如“拍肩膀以上，镜头比眼睛略高一点，右边留些球场”。

写英文提示词时，角色会假设生图模型完全不认识自己。除了衣着、动作、环境和光线，还会写出人设中最有辨识度、在这个镜头里能看见的细节。例如，半身照可以突出角色设定中的宽肩和挺拔坐姿，“有点委屈”可以表现为眉头微蹙、嘴角下压。动漫、漫画和游戏角色默认使用符合原作的插画风格，真人角色默认使用写实摄影。你也可以指定其他画风，例如黑白漫画。

保存识图提示词

发图片时，在“总结要求”中填写要求，点击保存提示词。下次从选择已保存的提示词中选择即可填入，仍可编辑；点击删除所选可删除保存项。每个账号最多保存30条，每条最多2000字，聊天与朋友圈共用。保存和选择提示词不会调用模型，也不会自动发送图片。取消图片发送不会撤销已经保存或删除的提示词。留空使用系统默认要求，手动描述不使用这些提示词。

发送图片与配文

单聊和群聊都支持以下用法，每次选择一张图片。AI 识图使用你配置的识图模型，手动描述不会调用识图模型；两种模式都能添加配文。

  1. 在聊天输入框右侧点击加号 → 图片，选择图片，打开“发送图片”窗口。输入框中已有的文字会自动带入配文。
  2. 选择AI 识图，可在“总结要求”中指定希望模型关注什么，例如“重点描述人物的衣着、表情和动作，用三句话总结”。也可选择手动描述，自行填写图片内容。
  3. 在想对 TA 说些什么中填写要一起发送的话，可用 [图片] 指定图片位置。
  4. 展开发送预览检查顺序，再点击发送。文字和图片会按顺序显示为多个气泡，作为同一条用户消息发送。

当用户语言与当前角色或群聊的交流语言不同时，配文输入框上方会出现与普通聊天相同的黄色翻译框。输入原文后点击翻译或按 Enter，译文会填入配文框并更新预览；Shift+Enter 换行。已有配文时会先确认替换。翻译会保留 [图片]、/ 和链接，完成后仍需点击发送。未手动修改译文时，发送后附上翻译前原文；翻译失败保留草稿，取消图片窗口不会改动主聊天草稿。

填写本次总结要求

在“总结要求（可选）”中直接输入希望 AI 如何描述这张图片，例如关注人物穿搭、提取图片文字，或限制总结句数。最多 2,000 字，留空则使用系统默认要求；只对本次图片识别生效。

用 / 分气泡，用 [图片] 指定位置

在配文中手动输入 /，可把文字分成多个气泡。点击“插入图片位置”会在光标处放入 [图片]，也可手动输入。例如：

今天买了新衣服/给你看看[图片]怎么样？

发送时会自动在图片和前后文字之间补分隔符，依次显示“今天买了新衣服” → “给你看看” → 图片 → “怎么样？”。不必手动给 [图片] 加 /；已有分隔符时不会重复添加，网址中的斜杠会保留。

  • 不写 [图片] 时，图片放在配文最后；不写配文时，只发送图片。
  • 每张图片只指定一个位置，重复输入标记时需要先删除多余标记。[图片]、[IMAGE] 和 [画像] 都可使用。
  • 这个位置标记用于选图后的配文窗口；在普通消息框中单独输入它不会上传图片。

取消发送或遇到失败

取消图片窗口会保留聊天输入框原有的草稿；窗口内临时修改的配文、总结要求和未发送图片不会在关闭或刷新后恢复。

上传、识图或消息保存失败时，窗口会保留当前内容，可检查后重试；识图失败也可点击改用手动描述。已成功识图且未更改描述方式或总结要求时，在同一窗口重试发送会复用已有结果。图片消息已经保存、只是角色回复失败时，使用聊天中的重试入口重新生成回复，无需重新上传图片。

7. 配置群聊并聊天

在联系人页点右上角的放大镜，可按角色姓名、备注或群名搜索。要找同时包含多个角色的群聊，用全角 ； 或半角 ; 分隔关键词。例如 千；玲王 可找到同时包含千切豹马和玲王的“女子会”，即使群名里没有这些名字。

新建群聊或改群名时，最多可用 15 个全角字符，两个半角字符算一个。

角色发起群聊时可以自己起名，也可以只选成员。没起名时会用顿号连接成员名，例如“千切、玲王”。如果群名超长，会改用“发起人名 · 群聊”，仍然超长就叫“群聊”。成员相同的群会沿用原来的群名。如果是新群，而同账号已有同名群，就从 2 开始取第一个可用编号，例如“女子会 2”“女子会 3”。编号也算在 15 个全角字符以内，必要时会缩短新群名的末尾。

群聊也可发送图片与配文，总结要求、图片位置标记和发送预览的用法与单聊相同。

  1. 在联系人页面点击右上角加号，选择新建群聊。
  2. 填写 ID（英文字母、数字、下划线）和群名称，选择至少两位角色成员。创建时不需要选择自己。
  3. 进入群聊，点击右上角设置入口，打开群聊记忆页面。
  4. 在基本信息中配置群聊交流语言、主动消息、置顶、群聊模式，以及“包含用户”。包含或不包含用户是同一个群聊的设置，不会创建另一份群聊。

群聊语言优先于角色语言：设置后，所有角色在该群内使用群聊指定语言。目前不能修改已建群聊的成员，需要更换成员时请新建群聊。

使用 @ 指定回复成员

  • @所有人：全体成员按随机顺序回复。
  • @单个成员：指定成员回复。
  • @多个成员：所选成员按提及顺序依次回复。

8. 语音电话

当前仅支持与单个角色进行一对一通话。

  1. 在角色聊天页点击输入框右侧加号，选择“语音通话”。
  2. 角色接听后会先说第一句话。配置了可用的角色音色时，你会听到声音；角色说完后，麦克风会进入收音状态，你可以开口回应。
  3. 你可以随时挂断，角色也可以结束通话。
  4. 当你在线且角色主动打来电话时，页面会进入来电界面，你可以接听或挂断。

首次使用需允许麦克风访问。角色会按人设决定是否接听；声音配置方法见ElevenLabs 私有音色。

9. 角色记忆机制

记忆何时整理？

角色在单聊、群聊、朋友圈之间切换互动场景时，会触发相关短期记忆整理。日常连续聊天时，请适时点击聊天页右上角的大脑按钮手动总结。

  • 每日北京时间 04:00：按北京时间整理上一日记忆，将短期记忆归纳为中期记忆；群聊内容会先总结并分发。
  • 每周一北京时间 04:00：将上一周中期记忆归纳为长期记忆；所有账号统一按北京时间划分日期和周。

记忆面板的日期和时间统一为北京时间（UTC+08:00）。群聊记忆分发给角色时仍保存北京时间；角色回复时，系统才按事件发生日期换算为角色所在地时间，并自动适配冬令时和夏令时。

自动总结依赖后台任务正常运行和模型调用成功；没有素材时会跳过。日结整理的是已过去的一天，并非清空聊天记录。

角色每次回复会读取什么？

除人设等核心资料外，通常包含：当前场景最近 20 条上下文、最近 24 小时短期记忆、近 7 天中期记忆，以及经过关键词和时间检索筛选的长期记忆。系统可调用轻量模型辅助提取检索信息，并结合时间顺序组织记忆。

保存了聊天记录，不代表每次回复都会读取全部历史。如果聊天已超过 20 条，而较早内容还没有总结进记忆，角色可能暂时“想不起”这些内容。重要互动后及时总结会更稳妥。

查看、编辑和重新生成

  • 每条记忆都可以编辑或删除；短期记忆可按日期跳转查看。
  • 重新生成某日短期记忆，只替换该日的单聊记忆，不替换来自群聊和朋友圈的记忆。
  • 中期、长期记忆也支持 AI 重新生成。生成失败时请检查提示后重试。
  • 群聊总结会分发到每位角色成员的短期记忆。重新生成群聊记忆会再次追加分发，不会自动删除之前已分发的版本；需要去重时请手动整理。

10. 角色状态说明

情绪指数
影响角色主动发消息的概率与频率，后台最快每 10 分钟检查一次；并不保证每 10 分钟发一条。 单聊最近 10 分钟内有新消息，或角色正在回复时，后台会跳过本轮主动消息检查。若主动生成期间来了新消息，过时的主动回复会被丢弃。
性格指数
影响主动发朋友圈的概率与频率，后台最快每 30 分钟检查一次。情绪指数和性格指数都可锁定，锁定后角色不能自行修改。
亲密度
可随聊天变化，也影响角色对用户朋友圈点赞、评论的概率。
聊天模式
线上模式可使用特殊消息，通常不描写动作与环境；线下模式侧重动作与环境描写，不使用线上特殊消息。线下可在深睡眠时回应用户，但不会主动发消息。
浅睡眠
开启后角色不会主动发送消息。新角色默认开启。
角色时区
影响角色的时间认知。深睡眠按设置中的时间基准生效：可按角色当地时间，也可按用户时间理解；请同时检查睡眠时间设置。
深睡眠
开启后角色在线上模式下不会回复，也不会主动发朋友圈。
睡前总结
开启后，角色进入深睡眠时会触发当天总结，并给出一段内心独白。联系人页面的总开关也必须开启；只开启角色自己的开关不会生效。

11. 多选聊天记录

在聊天页右上角点击中间的多选按钮，选择需要处理的气泡。先选一条，再长按另一条，或按住 Shift 点击另一条，可连续选中两条之间的气泡。

  • 转发：发送到花期内其他角色的单聊或群聊。
  • 生成记录：导出文字版或图片版；图片版可选择是否显示角色名。
  • 批量删除：删除选中的聊天记录，提交前请核对范围。

12. 多选聊天

在联系人页面点击右上角从右数第三个多选按钮，选择要处理的单聊或群聊。可为所选项目安排以下操作，最后点击保存统一执行。

  • 通用：设为已读、删除、置顶、取消置顶。
  • 仅单聊：开启或关闭浅睡眠；开启或关闭深睡眠；设置深睡眠时间；开启或关闭睡前总结；设置性格指数。
  • 仅群聊：开启或关闭主动消息。

删除角色还会清理其关联的聊天、记忆、朋友圈互动和地图位置，请以保存前的确认提示为准。

13. 朋友圈

  • 点击页面左上角的文字，可筛选查看某个角色的朋友圈。
  • 右上角左侧按钮用于开启或关闭主动朋友圈。
  • 右上角右侧按钮用于发朋友圈：可选择自己发布，或让指定角色发布，并提示角色想发什么。

每条朋友圈支持复制、点赞、翻译、评论、编辑和删除。评论时可选择自己或角色；角色发布的内容还支持重新生成和重新记忆，自己发布的内容没有这两项。

每条评论支持翻译、回复、编辑和删除；回复时也可选择自己或角色。角色评论可重新生成或重新记忆，自己的评论没有这两项。正文和评论的翻译入口始终保留，译文使用用户语言；再次点击隐藏译文，再点会重新翻译。原文修改后旧译文自动失效。自己发布或回复前的翻译使用默认对话语言，译文填入草稿，可修改后再发送。

屏蔽部分角色

自己发朋友圈时，点击谁不可见，勾选角色并确认。设置只对本条朋友圈生效，发布成功后下一条恢复为所有角色可见。

角色也可以自主屏蔽：在发布内容末尾，独占一行输出 ~~角色名~~，多位角色各写一行，也可使用备注或角色 ID。名字有重名时使用 ID。系统会保存名单并移除这些指令，不会显示在正文中。

被屏蔽角色不会随机点赞、评论；正文或评论中的 @、手动指定评论与回复也不能绕过屏蔽。手动选择时会标注对此条不可见。屏蔽名单按角色 ID 保存，角色改名不会失效。

有屏蔽对象的朋友圈会在卡片底部左侧显示部分用户不可见，点击可查看名单。用户本人仍可查看该条朋友圈和名单。编辑正文保留名单；重新生成保留原名单，并合并角色新增的屏蔽对象。

如果另一项操作刚修改了你正在保存的朋友圈内容，请刷新朋友圈后重试。

自己发朋友圈时，添加图片后可在识图附加提示词（本条朋友圈共用）中输入要求，也可选择已保存的提示词。同一个要求用于这条朋友圈里所有选择“AI 识图”的图片；最多2000字，留空沿用默认要求。选择“手动描述”的图片不使用该要求。提示词不会作为朋友圈正文发布。全部图片改为手动描述后，提示词输入区会隐藏。发布失败保留文字、图片及提示词，可调整后重试；取消发布清空本次草稿，但不删除已保存的提示词。小屏或键盘弹出时可在弹窗内滚动，底部操作区位于导航栏上方。

14. 世界地图

新增或编辑地点时，可设置名称、描述、地图坐标和真实世界地点。真实世界地点用于匹配天气与时区；角色移到已匹配的地点时，会采用该地点的时区。

  • 角色可移动到自己认知中的地点，也可在 1 格范围内自由移动，还可以新增地点。
  • 选择角色后，可以手动移动其位置并修改地点认知。
  • 角色去过的地点会自动加入其认知。
  • 角色与用户移到同一地点时，单聊自动切换为线下模式；分开到不同地点时，自动切回线上模式。

15. 修改主题与背景

进入个人主页 → 页面风格设置，选择主题色并上传默认聊天背景。

某个角色或群聊也可使用独立背景，分别在角色记忆或群聊记忆页面配置。

16. 配置 ElevenLabs 私有音色

角色 TTS、试听和音色克隆使用你自己的 ElevenLabs 账户；API Key、私有音色和套餐额度都属于你本人。用户语音转文字由花期的平台 STT Key 提供，不消耗你的个人额度。Voice ID 不会上传到角色广场。

第一步：注册 ElevenLabs 并创建 API Key

  1. 通过 ElevenLabs 邀请链接注册或登录。
  2. 进入账户设置中的 API Keys 页面，创建一个新的 Key。
  3. 确保该 Key 可以使用 Text to Speech 和 Voices/Voice Cloning；不需要为个人 Key 开启 Speech-to-Text。
  4. 创建后立即复制并妥善保存，切勿把完整 Key 发给其他人。

第二步：在花期加密保存 Key

进入个人主页 → 账号与通知设置 → ElevenLabs，粘贴 Key 并点击“保存/覆盖”。保存后页面只显示配置状态和末四位，不会回显完整 Key。

第三步：给角色创建音色

  1. 打开联系人，进入该角色的记忆与角色设置 → 语音设置。
  2. 填写音色名称，上传不超过 20 MB、声音清晰且只有一位说话人的音频。
  3. 确认你拥有该声音的使用权或已经获得声音本人明确授权。
  4. 点击“上传并创建音色”。成功后 Voice ID 会自动填入并保存到当前角色。
  5. 点击“试听音色”确认效果；之后角色发送的语音会消耗你自己的 ElevenLabs 套餐额度。

花期只会把本次上传的音频转发给 ElevenLabs 创建音色，不会长期保存该文件。你也可以手动填写当前 ElevenLabs 账户有权访问的 Voice ID；其他账户的私有 Voice ID 不能仅凭 ID 使用。

常见语音错误

  • API Key 无效或未配置：回到个人主页重新保存个人 ElevenLabs Key，避免前后空格。
  • 权限不足 / IP 白名单拒绝：检查 Key 是否允许 TTS 和音色操作；若启用了 IP 白名单，请更新允许范围。
  • Voice ID 无法使用：确认音色属于当前账户，或是该账户能够访问的共享音色。
  • 额度不足或音色数量已满：检查个人套餐和已保存音色数量，删除不需要的音色或按需调整套餐。

17. 角色广场

在角色广场搜索喜欢的角色，先试聊，或直接添加到自己的联系人。也可以发布自己的角色，并从本地已有角色导入资料。

上传时可填写：ID（系统会处理重复）、角色名称、别名、年龄（可选择不随时间增长）、所属 IP、角色标签、人际关系图谱与角色人设。

在角色详情下方可以查看同一作者发布的其他角色。你可以点赞、收藏角色，也可以匿名评论。

18. 论坛

  1. 在联系人页点击右上角加号，选择“论坛生成”。
  2. 填写主题，选择类型和楼数；可载入多段聊天记录，也可选择历史论坛进行续写。
  3. 选择生成语言，填写补充信息，然后开始生成。内容会流式显示，逐步出现在页面上。
  4. 复制生成结果的论坛块代码，粘贴到聊天中发送，即可按论坛格式显示。

19. 错误码、报错与熔断机制

遇到错误时，先查看当前线路和模型，再根据提示检查 Key、余额、权限或网络。页面可能显示翻译后的简短错误，不一定显示上游的原始文字。

哪些错误会计入熔断？

当前调用方式计入熔断的 HTTP 状态码
Gemini 直连的普通模型调用400、403
ChatGPT、Claude、Grok、自填写线路，以及论坛流式生成（含 Gemini）400、401、402、403
仍在使用的旧 relay 兼容调用401、402、403、525；与当前“自填写”不同。

上表针对聊天、总结等通用模型调用和论坛流式调用。生图、语音、网页访问等独立功能有各自的报错与限制，不能仅凭同一个数字认定会触发相同熔断。

计数、冷却和恢复

  1. 按用户 + 线路 + 同一错误码分别计数，首次出现给出警告。
  2. 同一错误累计第二次，进入10 分钟冷却，期间对应线路的受保护调用会被拦截。
  3. 冷却后若计数尚未复位，再出现同一错误达到第三次，该线路会被禁用。这是线路限制，不会因此冻结整个账号。
  4. 未禁用的计数在该线路调用成功后清除；距最后一次错误超过30 分钟且不在冷却中，也会在下次检查时复位。
  5. 已禁用的线路不会因等待 30 分钟或更换 Key 自动恢复。修正配置后联系管理员解除；也可以切换到另一条配置正确的线路。

常见错误怎么处理？

400 · 请求不符合接口要求
检查模型 ID、接口格式、输入类型和参数。自填写线路尤其要确认所选协议与服务商一致。
401 · 身份验证失败
AI 服务报错时检查 API Key 是否正确或已失效；如果是网站页面接口提示登录失效，则重新登录花期。
402 · 余额或计费问题
到对应服务商检查 API 余额、套餐与计费状态。
403 · 访问被拒绝
检查模型权限、账号或地区限制、Key 权限及服务商访问策略；它不只代表模型名称错误。
404 · 模型或接口不存在
检查模型是否下线、当前 Key 是否有访问权限，以及 API 地址是否填写正确。以上通用调用不将 404 计入熔断。
429 · 限流或配额不足
减少并发和发送频率，查看服务商配额或余额。以上通用调用不将 429 计入熔断。
500 / 502 / 503 / 504 · 上游故障或超时
稍后再试，必要时缩短输入或换用响应更快的模型；不计入上述致命错误计数。网站返回 503 也可能表示服务未配置或线路正处于熔断，需结合提示判断。
524 / 525 · 代理超时或连接问题
检查线路服务状态。当前自填写线路不把这两项计入熔断；仅旧 relay 兼容调用将 525 计入。
空回复、解析失败、输出截断或流式中断
模型未返回完整有效内容。检查输入长度和模型能力，稍后重试；不能把部分输出当作完整生成成功。
记忆同步或总结失败
检查记忆模型与线路设置，再手动总结。失败时本次回复可能缺少新整理的记忆，请以页面提示为准。

主动任务遇到致命错误或熔断时，可能自动开启角色浅睡眠、关闭对应群聊主动消息或关闭主动朋友圈。修好线路后，请检查这些开关并按需重新开启。

需要协助时，请提供功能名称、线路、模型、错误码、发生时间和已遮盖敏感信息的截图。不要发送完整 API Key、密码或验证码。解除限制后先用一条短消息验证配置。

20. 把网站安装成 PWA 应用

把花期添加到手机桌面后，可以像普通 App 一样点击图标进入，不必每次寻找网址。这是网站的 PWA 版本，无需下载 APK 或经过应用商店。

PWA 仍然需要网络才能正常聊天。安装只会添加应用入口，不会创建新账号；继续使用原来的邮箱和密码登录。

三步安装

  1. 在手机浏览器打开花期首页，等待页面完整加载。
  2. Android 打开“⋮”或菜单；iPhone Safari 点击分享。
  3. 选择“安装应用”或“添加到主屏幕”，确认后查看桌面上的花期图标。

Android · Chrome

  1. 使用 Chrome 打开花期首页。
  2. 点击地址栏旁或右上角的“⋮”。
  3. 选择“添加到主屏幕 → 安装”；部分版本直接显示“安装应用”。
  4. 按提示确认，返回桌面查看图标。

Android · Firefox（推荐）

  1. 使用 Firefox 打开花期首页。
  2. 打开浏览器菜单。
  3. 选择“安装”；如果只看到“添加到主屏幕”，选择它也可以。
  4. 点击“自动添加”，或按提示将图标拖到桌面。

iPhone / iPad · Safari

  1. 使用 Safari 打开花期首页。
  2. 点击分享按钮（方框上方有向上箭头）；部分布局需先点“更多”，再点“分享”。
  3. 向下滚动，选择“添加到主屏幕”。
  4. 如果看到“作为 Web App 打开”，将它开启，然后点击“添加”。

其他 Android 浏览器

  1. 打开网站，点击“三个点”或“三条横线”菜单。
  2. 寻找“安装应用”“添加到桌面”或“添加到主屏幕”。
  3. 确认名称与图标后完成添加，具体文字和位置因浏览器而异。

找不到安装入口怎么办？

  • 菜单没有“安装应用”：寻找“添加到主屏幕”或“添加至桌面”，等待加载后刷新，或更新浏览器。
  • iPhone 没有“添加到主屏幕”：确认使用 Safari，在分享菜单底部的“编辑操作”中添加此项。
  • 安装后仍显示地址栏：可能添加的是网页快捷方式。可删除图标后重新操作，优先选择“安装应用”或开启“作为 Web App 打开”。
  • 不能离线聊天：这是正常现象，聊天、同步和 AI 回复仍需联网。

iPhone / iPad 如需消息推送，请先添加到主屏幕，从桌面图标打开，再到个人主页 → 浏览器消息推送开启权限。

21. 账号与使用安全

下面的提示帮助你管理账号与使用时间，不会改变正常的角色聊天体验。

开通账号的年龄要求

花期仅面向已满 18 周岁的用户。请在联系管理员开通账号前确认自己符合年龄要求。

连续使用 2 小时提醒

连续使用超过 2 小时，页面会弹出健康使用提醒。它不会强制下线、暂停聊天或影响 AI 回复。

安全提示

对话中出现明显人身安全风险时，页面可能在消息附近显示居中的灰色提示，提醒你联系身边可信任的人或当地紧急服务；在中国，也可拨打全国统一心理援助热线 12356。

安全提示不能替代专业帮助。若你或身边的人处于紧急危险中，请优先联系身边可信任的人或当地紧急服务。

注销账户

在个人主页底部点击“注销账户”，阅读影响提示，再点击“继续注销”。输入当前密码，并手动输入页面要求的确认文字后提交。

  • 删除范围：清理账号、个人配置、私有聊天与媒体、试聊、可关联到你的评论及使用记录。请先保存自己需要的内容。
  • 公开投稿：公开角色和表情包会保留，但移除作者账号、邮箱及源角色关联。正文中自行填写的信息、无法归属的历史评论、他人保存的副本及第三方记录不会自动清除。若希望删除投稿，请在注销前处理。
  • 恢复：已删除的数据无法恢复；云端清理失败时可按页面提示重试。
  • 密码错误：不会执行注销，必须通过密码和确认文字校验。

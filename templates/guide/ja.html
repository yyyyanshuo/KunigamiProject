1. アカウント開設・ログイン・パスワード再設定

アカウント開設を申し込む

  1. 管理者（yyyyanshuo@foxmail.com）にメールで連絡し、受信できるメールアドレスと希望のニックネームを伝えてください。
  2. 管理者の案内に従い、アカウント開設料9.9元（人民元）をお支払いください。
  3. 開設後、管理者からログイン用のアカウント情報と初期パスワードが届きます。登録メールアドレスと初期パスワードで咲きにログインし、プロフィールでパスワードを変更してください。
  4. 利用規約とプライバシーポリシーを読み、プロフィールで確認してください。咲きは現在、18歳以上の方を対象としています。

実際にメールを受信できるアドレスを使用し、パスワードを大切に保管してください。通知用メールアドレスと登録メールアドレスは用途が異なります。パスワード再設定には登録メールアドレスが必要です。

ログインする

ログインページで登録メールアドレスとパスワードを入力します。ログインページとパスワード再設定ページには「使い方ガイド」ボタンがあり、新しいタブでこのガイドを開けます。

パスワードを忘れたとき

  1. ログインページの「パスワード再設定」から再設定ページを開きます。
  2. 登録メールアドレスを入力して確認コードを送信します。受信トレイと迷惑メールフォルダーを確認してください。
  3. メールに記載された6桁の確認コードと新しいパスワードを入力します。コードの有効期間は10分です。再送した場合は最新のコードを使用します。
  4. 送信して再設定が完了したら、ログインページで新しいパスワードを使ってログインします。以前のログイン状態では再認証が必要になります。

送信ボタンには約60秒の再送待ち時間があります。期限切れの場合はコードを再取得してください。届かない状態が続く場合や、登録したメールを使えない場合はサポートへ連絡してください。配信状況はメールサービスと受信側の状態によって変わります。

2. 自分のプロフィールを設定

  1. プロフィールでアイコンと表示名を設定します。
  2. アカウント・通知設定で年齢、つつくときの接尾辞、デフォルトの会話言語などを設定します。
  3. 共通ユーザー設定 → 編集で自分自身の設定を書き、保存します。

デフォルトの会話言語は、キャラクターとの会話や自分のタイムライン投稿に使う言語です。「自分の世界の中で使う言語」と考えてください。内蔵翻訳で下書きを会話用の言語に訳し、必要に応じて直してから送信できます。キャラクターやグループに個別の言語を設定している場合は、そちらが優先されます。

ユーザー言語は画面表示と、読むための翻訳に使われます。ページの言語選択から変更でき、世界の中の言語と異なっていても構いません。例えば画面は日本語、デフォルトの会話言語は英語にすると、日本語で書いた下書きを英語に訳して送れます。

別々の設定画面から異なる項目を同時に保存しても、それぞれの変更が反映されます。

3. 通知を受け取る

  1. メール通知：プロフィール → アカウント・通知設定の「通知用メールアドレス」に、通知を受け取りたいアドレスを入力します。
  2. ブラウザーのプッシュ通知：プロフィール → ブラウザー通知で「通知を有効にする」を選択します。Firefoxを推奨します。ほかのブラウザーでは有効化できない場合があります。
同じ端末で複数のアカウントを使う場合：通知を受け取りたい各アカウントにログインし、それぞれで通知を有効にしてください。同じ端末で、有効化した複数アカウントの通知を受信できます。

4. 接続先とモデルを設定

プロフィール → 接続先とモデル設定 → 設定を開き、次の順で操作します。

  1. 接続先を選ぶ：Gemini、ChatGPT、Claude、Grok、または「カスタム」を選択します。カスタムでは、接続名、HTTPSのAPIアドレス、提供元に対応するAPI形式も入力します。
  2. APIキーを入力する：選択中の接続先に対応するキーを入力します。異なる提供元のキーは使い回せません。カスタムも、その接続先用に発行されたキーが必要です。保存済みのキーは全文表示されません。
  3. モデルを選ぶ：チャット、翻訳、画像認識、人物設定、通話、タイムライン、記憶、画像生成、掲示板に使うモデルを個別に選びます。一覧にない場合は、提供元が実際に対応している正確なモデルIDを追加できます。
  4. 必要に応じて1日の画像生成上限を設定し、設定を保存します。キーとモデルの変更は保存後に反映されます。

モデルの選び方：Geminiを例に

同じ世代なら、Pro → Flash → Flash-Liteの順に速度やコストを重視する傾向があります。Proは複雑な作業や細部の表現を重視する選択です。ただし世代が異なる場合は実際の能力を比較し、Pro・Flashという名前だけで順位を決めないでください。

5. キャラクターを作成・設定

新しく付けるキャラクター名や表示名は全角10文字までです。半角英数字は2文字で全角1文字分として数えます。既存の長い名前は引き続き使えます。

  1. 連絡先ページ右上のプラスから、新しい連絡先を作成します。
  2. IDと名前を入力します。IDに使えるのは英字、数字、アンダースコアです。
  3. そのキャラクターのチャットを開き、右上の設定入口からキャラクターの記憶ページへ進みます。
  4. キャラクタープロフィール → 基本情報 → プロフィール編集で、アイコン、表示用の呼び名、年齢、つつくときの接尾辞、会話言語、ピン留めを設定します。
  5. 基本設定 → 人物設定でキャラクターの設定を編集します。自分で入力するほか、名前と作品名（IP）を指定してAI生成できます。AI用プロンプトをコピーして自分のAIに渡し、結果を貼り付けることもできます。
  6. 基本設定 → 関係図で関係を編集します。「自分の視点」は現在のキャラクターが他者をどう見ているか、「他者の視点」は他のキャラクターが現在のキャラクターをどう見ているかを表します。カード編集、JSON編集、AI生成に対応します。プロンプトを自分のAIに渡し、返されたJSONで編集欄を置き換える方法も使えます。カード編集ではキャラクターからあなたへの見方も追加しましょう。
  7. 任意で動的記憶 → 直近の予定に予定を設定します。1件ずつ追加するほか、「高度なツール」のソースコードモードで全体を置き換えられます。他のキャラクターから予定をコピーしたり、現在の予定を他のキャラクターへ同期したりすることもできます。

🔒 人物設定をAIの編集から保護する

守りたいコア設定を、独立した行の [[LOCK]] と [[/LOCK]] で囲みます。

[[LOCK]]
# 原作のコア設定
- 公式の身分、外見、経歴、変わらない性格
[[/LOCK]]

# 今後調整してよい追加設定
- ユーザーと過ごすうちに身についた習慣

キャラクターとモデルは保護された内容も読み取り、後からAIが人物設定を編集・書き直す際は区間内の文章を保持します。あなた自身の編集は制限されません。編集欄は通常のテキストなので、区間内の文章の変更、タグの移動や削除、保護範囲の変更も自由です。保存後は新しい内容が基準になります。

タグを残す場合は開始と終了を対にし、それぞれ独立した行に置き、入れ子にしないでください。AI生成では明確な公式・原作情報を保護し、推測や創作の補足、交流の好みはタグの外に置きます。通常の会話では内容を参照しますが、タグについて自分から説明することはありません。

6. キャラクターと会話

チャット名は上部のツールバーの中央に表示され、個別チャットではその真下にキャラクターの状態が表示されます。画面が狭い場合、長い名前は記憶ボタンなどの背後まで表示されます。ボタンはそのまま押せて、ツールバーの高さも一定です。左上の矢印で戻り、その隣の虫眼鏡で履歴を検索できます。戻るボタンと右側のボタンは、画面端から同じ間隔で並びます。矢印と虫眼鏡の間にある薄いグレーの半透明の丸には、ほかの個別チャットとグループチャットの未読件数だけが表示されます。開いているチャットに新着メッセージが届いても、この件数は増えません。約3秒ごとに新着メッセージと一緒に未読件数とキャラクターの状態を更新します。ほかのチャットの未読がゼロになると丸は消えますが、虫眼鏡の位置は変わりません。過去のメッセージを読んでいる間も、表示位置を保ったまま状態と件数が更新されます。未読件数を一時的に取得できない場合は丸を隠し、更新に成功した時点で最新の件数を表示します。上部のボタンを押している間は薄いグレーの背景が表示されます。戻るボタンは矢印と未読件数を囲むカプセル形で、ほかのボタンは同じ高さの円形です。

  1. 入力欄に文章を入れて送信します。
  2. ユーザー言語とキャラクターの会話言語が異なると、送信欄の上に翻訳欄が表示されます。キャラクターの言語が未設定ならデフォルトの会話言語を使います。下書きを翻訳すると送信欄に訳文が入り、必要なら修正して送れます。訳文を変更せずに送った場合、吹き出しの下に翻訳前の原文が添えられます。
  3. 入力欄の左にある音声ボタンで録音モードに切り替え、「長押しして話す」を押し続けて録音します。必要に応じてマイクを許可してください。録音中に上へスライドするとキャンセルできます。
  4. 入力欄の右にあるプラスで、画像、スタンプ、定型文、送金、音声通話、ウェブサイトのパネルを開きます。
  5. キャラクターのアイコンをダブルクリック・ダブルタップすると、相手をつつけます。
  6. キャラクターのメッセージメニューから、対象となる最後のメッセージの音声再生成、再生、翻訳、編集、削除、コピーができます。翻訳はユーザー言語と実際の会話言語が異なる場合に表示されます。
  7. キャラクターから送金が届いたら、受け取るか返却できます。チャット内の架空のやり取りです。

プラスから使える機能

  • 画像：AI画像認識または手動の説明を選び、要約の指示を入力したり、言葉を添えて送ったりできます。詳しくは画像に言葉を添えて送るをご覧ください。
  • スタンプ：ハートのタブから自分で追加したスタンプを使えます。追加時には説明を入力します。プラスタブではスタンプパックを追加でき、自作パックの公開アップロードや検索も可能です。
  • 定型文：よく使う指示や短い文章を保存できます。選ぶと入力欄の末尾に追加されるので、確認して送信します。
  • 音声通話：現在のキャラクターに電話します。
  • ウェブサイト：URLを入力し、アクセス可能なページの内容をキャラクターに読ませます。

送金と添えるメッセージ

送金・画像・タイムラインの編集画面では、画像認識の指示欄はタイムライン本文の入力欄と同じ文字サイズです。入力中の欄にピンクの枠が表示されます。保存済みの指示は角丸のプルダウンから選べます。内容が画面に収まらない場合は画面内をスクロールできます。

入力欄の＋ → 送金から、金額、通貨（CNY、USD、JPYや通貨記号）、任意のメモを入力し、送信します。金額は0より大きく、小数点以下2桁まで、上限は999999999.99です。メモは80文字以内で、[ ] | / や改行は使えません。チャット内の仮想的なやり取りであり、実際の支払いは発生しません。

キャラクターから届いた未処理の送金カードを押すと、受け取り・返却を選べます。送金・受け取り・返却のいずれもメッセージを添えられます。チャットの下書きが画面に引き継がれ、/ でメッセージを区切れます。送金カードは最後に表示されます。言語が異なる場合は画面内で翻訳し、編集後に送信できます。キャンセルしても送信や送金処理は行われず、チャットの下書きは残ります。送信失敗時も入力内容を保持し、保存に成功したときだけ元の下書きを消去します。同じ送金を受け取る・返却する操作は一度だけです。

キャラクターに画像を作ってもらう

オンラインモードの個別チャットやグループチャットで、「練習が終わってコート脇に座っているところを、自撮りして送って」と頼んでみましょう。自撮りでは、キャラクター自身のスマホのカメラに映る景色を描写します。「肩から上を写して。カメラは目より少し高く、右側にコートが少し入るように」のように、写す範囲や角度、被写体の位置も指定できます。

キャラクターは、自分をまったく知らない画像生成モデルにも姿や場面が伝わるように、英語で指示を書きます。服装や動作、場所、光に加えて、その構図で見える、その人らしい特徴を伝えます。たとえば上半身の写真では設定にある肩幅の広さや背筋の伸びた座り姿を、「少しすねた顔」ならわずかに寄せた眉や下がった口角を描写します。通常、アニメ・漫画・ゲームのキャラクターには原作に合ったイラスト調、実在の人物をもとにしたキャラクターには写実的な写真調を使います。白黒漫画風など、別の画風も指定できます。

画像認識の指示を保存

画像送信画面の要約指示を入力し、指示を保存を押します。次回は保存済みの指示を選択から呼び出し、編集できます。選択項目を削除で保存項目を削除できます。アカウントごとに30件まで、1件2000文字まで保存でき、チャットとタイムラインで共用します。保存・選択だけではモデルを呼び出さず、画像も送信しません。画像送信をキャンセルしても、すでに保存・削除した指示は元に戻りません。空欄なら標準の指示を使い、手動説明ではこれらの指示を使いません。

画像に言葉を添えて送る

個別チャットとグループチャットの両方で使えます。一度に選べる画像は1枚です。AI画像認識には設定済みの画像認識モデルを使い、手動の説明ではそのモデルを呼び出しません。どちらでも言葉を添えられます。

  1. チャット入力欄の右にあるプラス → 画像から画像を選ぶと、「画像を送信」画面が開きます。入力欄にある下書きは、画像に添える文章の欄へ自動でコピーされます。
  2. AI画像認識では、「服装、表情、動作を中心に3文でまとめてください」など、任意で要約の指示を入力できます。手動で説明を選び、自分で画像の内容を書くこともできます。
  3. 一緒に送りたい言葉に、キャラクターへ伝えたい文章を入力します。[画像] で画像を置く位置を指定できます。
  4. 送信プレビューを開いて順番を確認し、送信します。文章と画像は順番に別々の吹き出しで表示されますが、1件のユーザーメッセージとして送られます。

ユーザー言語と現在のキャラクターやグループの会話言語が異なる場合、文章欄の上に通常のチャットと同じ黄色い翻訳欄が表示されます。原文を入力して翻訳または Enter を押すと、訳文が文章欄に入り、プレビューも更新されます。Shift+Enter で改行でき、下書きがある場合は置き換える前に確認します。[画像]、/、リンクは保持され、送信は確認後に自分で行います。訳文を手動で変更しなければ、送信後のメッセージに原文も表示されます。翻訳に失敗しても下書きは残り、画像画面を閉じても通常のチャットの下書きは変わりません。

入力する内容役割吹き出しに表示されるか
要約の指示画像認識モデルに、どのようにまとめるかを伝える表示されず、添える文章としても送られません
AIによる説明・手動の説明キャラクターが画像の内容を理解するための説明。AIは500文字、手動は4000文字以内画像のみ表示され、説明文は表示されません
一緒に送りたい言葉キャラクターへ伝える言葉文字の吹き出しとして表示されます

今回の画像の要約方法を指定する

「要約の指示（任意）」に、AIに注目してほしい内容を直接入力します。例えば、服装を中心に説明する、画像の文字を抽出する、文の数を指定するといった指示ができます。2,000文字以内で入力し、空欄の場合は標準の指示を使います。入力した指示は今回の画像認識にのみ使われます。

/ で吹き出しを分け、[画像] で位置を指定する

添える文章に / を入力すると、文字の吹き出しを分けられます。「画像の位置を挿入」でカーソル位置にマーカーを入れるか、[画像] を直接入力します。例：

新しい服を買ったよ/見てみて[画像]どう思う？

画像と前後の文章の間には区切りが自動で入り、「新しい服を買ったよ」→「見てみて」→ 画像 →「どう思う？」の順で表示されます。区切りがすでにある場合は重複して追加せず、URL内のスラッシュはそのまま保ちます。

  • 位置を指定しなければ、文章の最後に画像を置きます。文章が空欄なら画像だけを送ります。
  • 1枚の画像につき指定できる位置は1か所です。余分なマーカーは送信前に削除してください。[画像]、[图片]、[IMAGE] は同じ意味です。
  • 位置の指定は、画像を選んだ後の文章欄で使います。通常のチャット入力欄にマーカーだけを書いても、画像はアップロードされません。

キャンセルと送信失敗時の操作

キャンセルすると、通常のチャット入力欄に元からあった下書きは残ります。画像の送信画面で一時的に編集した文章や指示、未送信の画像は、画面を閉じたり再読み込みしたりすると復元されません。

アップロード、画像認識、メッセージの保存に失敗しても、開いている画面の内容は残るので再試行できます。画像認識に失敗した場合は手動で説明することもできます。認識が成功した後、説明方法や指示を変更せず同じ画面で再送すると、取得済みの結果を再利用します。画像メッセージは保存され、キャラクターの返答だけが失敗した場合は、チャット内の再試行から返答を生成し直せます。画像の再アップロードは不要です。

7. グループを作成して会話

連絡先ページの右上にある虫眼鏡から、キャラクター名、ニックネーム、グループ名で検索できます。複数のキャラクターがいるグループを探すには、キーワードを ； または ; で区切ります。たとえば 千；玲王 と入力すると、グループ名に名前が入っていなくても、千切豹馬と玲王がいる「女子会」を探せます。

グループを作成するときや改名するときは全角15文字までです。半角2文字を全角1文字として数えます。

キャラクターがグループを作るとき、名前は任意です。指定がなければ「千切、玲王」のようにメンバー名を読点でつなぎます。長すぎる場合は「発起人名 · グループチャット」を使い、それでも長ければ「グループチャット」にします。同じメンバーのグループがすでにあれば、元の名前を引き継ぎます。別のメンバーで作る新しいグループが同じアカウント内のグループと同名になる場合は、「女子会 2」「女子会 3」のように、2から順に最初の空き番号を付けます。番号を含めて全角15文字に収まるよう、必要に応じて新しいグループ名の末尾を短くします。

グループでも画像に言葉を添えて送ることができます。要約の指示、画像の位置指定、送信プレビューの使い方は個別チャットと同じです。

  1. 連絡先ページ右上のプラスからグループチャットを作成します。
  2. ID（英字・数字・アンダースコア）とグループ名を入力し、2人以上のキャラクターを選択します。作成時に自分を選ぶ必要はありません。
  3. グループチャットを開き、右上の設定入口からグループの記憶ページへ進みます。
  4. 基本情報で、グループの会話言語、自発メッセージ、ピン留め、チャットモード、「ユーザーを含める」を設定します。自分を含める場合も含めない場合も、同じグループの設定であり、別のグループにはなりません。

グループの言語は各キャラクターの言語より優先されます。設定すると、グループ内では全員がその言語を使います。作成済みグループのメンバーは現在変更できないため、変更したい場合は新しく作成してください。

@で返答する相手を選ぶ

  • @全員：全メンバーがランダムな順番で返答します。
  • @1人：指定したメンバーが返答します。
  • @複数人：指定したメンバーがメンション順に返答します。

8. 音声通話

現在は、1人のキャラクターとの1対1の通話に対応しています。

  1. チャットの入力欄右側のプラスを開き、「音声通話」を選びます。
  2. キャラクターが応答すると、相手から最初の一言を話します。利用可能な音声を設定していれば声が聞こえます。相手が話し終えるとマイクが受け付け状態になり、あなたが話せます。
  3. いつでも電話を切れます。キャラクターから通話を終了することもあります。
  4. オンライン中にキャラクターから電話が来ると着信画面が開き、応答するか切るかを選べます。

初回はマイクへのアクセスを許可してください。キャラクターは人物設定に応じて電話に出るかを判断します。声の設定はElevenLabsのプライベート音声を参照してください。

9. キャラクターの記憶の仕組み

いつ記憶が整理される？

個別チャット、グループチャット、タイムラインの間で交流場面が切り替わると、関連する短期記憶の整理が行われます。同じ場面で会話を続けるときは、適宜チャット右上の脳のボタンで手動要約してください。

  • 毎日、北京時間04:00：北京時間の前日の短期記憶を中期記憶にまとめます。グループの会話は先に要約して各メンバーへ配ります。
  • 毎週月曜、北京時間04:00：前週の中期記憶を長期記憶にまとめます。すべてのアカウントで記憶の日付と週の区切りに北京時間を使います。

記憶編集画面の日付と時刻は北京時間（UTC+08:00）です。グループの記憶を各キャラクターに配る際も北京時間で保存します。返答時に初めて、出来事の日付に応じてキャラクターの所在地の時刻へ変換し、夏時間・標準時間を自動適用します。

自動要約にはバックグラウンド処理の稼働とモデル呼び出しの成功が必要です。材料がない期間はスキップします。日次要約は過ぎた1日を整理するもので、チャット履歴を消す処理ではありません。

返答のたびに何を読む？

人物設定などの基礎情報に加え、通常は現在の場面の直近20件、過去24時間の短期記憶、直近7日間の中期記憶、キーワードと時期で検索・選別した長期記憶を参照します。軽量モデルが検索情報の抽出を補助する場合があり、記憶は時系列も考慮して組み立てられます。

履歴が保存されていても、毎回すべてを読み直すわけではありません。会話が20件を超え、古い内容がまだ記憶に要約されていないと、一時的に「思い出せない」ことがあります。大切なやり取りの後に要約すると安心です。

確認・編集・再生成

  • 各記憶を編集・削除できます。短期記憶は日付を選んで移動できます。
  • ある日の短期記憶を再生成すると、その日の個別チャット由来の記憶だけを置き換えます。グループやタイムライン由来の記憶は置き換えません。
  • 中期・長期記憶もAIで再生成できます。失敗した場合は表示された理由を確認してから再試行してください。
  • グループ要約は各キャラクターメンバーの短期記憶へ配られます。グループ記憶を再生成すると再び追記され、以前配った記憶は自動削除されません。必要なら重複を手動で整理してください。

10. キャラクターの状態

感情指数
自発メッセージを送る確率と頻度に影響します。バックグラウンドで最短10分ごとに確認しますが、毎回必ず送信するわけではありません。 個別チャットで直近10分以内にメッセージがある場合や、キャラクターが返信中の場合は、自発メッセージの送信を見送ります。自発メッセージの生成中に新しいメッセージが届くと、生成結果は破棄されます。
性格指数
自発的なタイムライン投稿の確率と頻度に影響し、最短30分ごとに確認します。感情指数と性格指数はどちらもロックでき、ロック中はキャラクターが変更できません。
親密度
会話のたびに変化することがあり、ユーザーの投稿へのいいねやコメントの確率にも影響します。
チャットモード
オンラインでは特殊メッセージを使え、通常は動作や周囲を描写しません。オフラインでは動作や周囲の描写を中心にし、オンラインの特殊メッセージを使いません。オフラインでは深い眠りの間もユーザーに返答できますが、自発メッセージは送りません。
浅い眠り
有効にすると自発メッセージを送りません。新しいキャラクターでは初期状態で有効です。
キャラクターのタイムゾーン
時間認識に影響します。深い眠りは設定した時間基準に従い、キャラクターの現地時間またはユーザーの時間を使います。睡眠時間の設定も併せて確認してください。
深い眠り
オンラインモードで返答しなくなり、自発的なタイムライン投稿も行いません。
就寝前のまとめ
有効にすると、深い眠りに入る際にその日の要約と内心の独白を生成します。連絡先ページの全体スイッチも有効である必要があり、個別設定だけでは動作しません。

11. メッセージの複数選択と書き出し

チャット右上の中央にある複数選択ボタンで吹き出しを選びます。1件選んでから別の吹き出しを長押しするか、Shiftを押しながらクリックすると、その間をまとめて選択できます。

  • 転送：咲き内の別のキャラクターやグループへ送ります。
  • 記録を作成：テキストまたは画像で書き出します。画像ではキャラクター名の表示を選べます。
  • 一括削除：選択したメッセージを削除します。実行前に範囲を確認してください。

12. チャットをまとめて管理

連絡先ページ右上、右から3番目の複数選択ボタンで個別チャットやグループを選びます。次の操作を設定し、最後に保存するとまとめて反映されます。

  • 共通：既読にする、削除、ピン留め、ピン留め解除。
  • 個別チャットのみ：浅い眠りのオン・オフ、深い眠りのオン・オフ、深い眠りの時間設定、就寝前のまとめのオン・オフ、性格指数の設定。
  • グループのみ：自発メッセージのオン・オフ。

キャラクターを削除すると、関連する会話、記憶、タイムラインでの交流、地図上の位置も整理されます。保存前の確認画面を読んでください。

13. タイムライン

  • 左上の文字を選ぶと、特定のキャラクターの投稿に絞り込めます。
  • 右上の2つのボタンのうち、左側で自発投稿をオン・オフします。
  • 右側で新規投稿します。自分として投稿するほか、キャラクターを選び、何を投稿してほしいか伝えることもできます。

各投稿にはコピー、いいね、翻訳、コメント、編集、削除ができます。コメントは自分またはキャラクターとして送れます。キャラクターの投稿には再生成と記憶の再作成もありますが、自分の投稿にはこの2項目はありません。

各コメントにも翻訳、返信、編集、削除があり、自分またはキャラクターとして返信できます。キャラクターのコメントは再生成・記憶の再作成ができますが、自分のコメントにはありません。投稿本文とコメントには常に翻訳メニューがあり、ユーザー言語に翻訳します。もう一度押すと訳文を隠し、さらに押すと再翻訳します。原文を編集すると古い訳文は無効になります。自分で投稿・返信する前の翻訳にはデフォルトの会話言語を使い、訳文が下書きに入るので、確認・修正してから送信できます。

一部のキャラクターに非表示にする

自分で投稿するときは非表示にする相手を開き、キャラクターを選んで確定します。この投稿にのみ適用され、投稿後は次の投稿の設定が「すべてのキャラクターに表示」に戻ります。

キャラクターも、投稿の末尾に ~~キャラクター名~~ を独立した行で出力して、相手に非表示にできます。複数人は1人ずつ改行します。備考名やキャラクターIDも使え、同名の場合はIDを指定します。指示行は本文から取り除かれ、リストとして保存されます。

非表示の相手はランダムないいね・コメント、@メンションによる参加、手動で指定するコメント・返信ができません。選択欄にはこの投稿は非表示と表示されます。IDで保存するため、改名後も有効です。

投稿カードの左下にある一部の相手に非表示を押すと、リストを確認できます。ユーザー本人は投稿とリストを引き続き見られます。本文の編集ではリストを保持し、再生成では元のリストを残して新たな非表示対象を追加します。

保存しようとしているタイムラインの内容が別の操作で変更された場合は、タイムラインを更新してから再度お試しください。

自分でタイムラインに投稿する際、画像を追加すると画像認識の追加指示（この投稿で共通）を入力でき、保存済みの指示も選べます。同じ指示がこの投稿内で「AI画像認識」を選んだすべての画像に適用されます。2000文字以内で、空欄なら標準の指示を使います。手動説明の画像には適用されず、指示が本文として公開されることもありません。全画像を手動説明にすると指示欄は非表示になります。投稿失敗時は本文・画像・指示を保持し、修正して再試行できます。キャンセルすると今回の下書きは消えますが、保存済みの指示は残ります。小さな画面やキーボード表示中は画面内をスクロールでき、操作ボタンは下部ナビゲーションより前に表示されます。

14. 世界地図

地点の追加・編集では、名前、説明、地図上の座標、現実世界の場所を設定できます。現実の場所は天気とタイムゾーンの照合に使われ、キャラクターが対応付けられた地点へ移動すると、その地点のタイムゾーンになります。

  • キャラクターは知っている地点へ移動でき、1マスの範囲でも自由に動けます。新しい地点を作ることもできます。
  • キャラクターを選ぶと手動で移動させたり、知っている地点を編集したりできます。
  • 訪れた地点は自動的にそのキャラクターの認知へ追加されます。
  • ユーザーとキャラクターが同じ地点に来ると個別チャットはオフラインに切り替わり、別の地点へ離れるとオンラインに戻ります。

15. テーマと背景を変更

プロフィール → テーマ設定でテーマカラーを選び、デフォルトのチャット背景をアップロードします。

特定のキャラクターやグループだけ別の背景にしたい場合は、それぞれのキャラクターの記憶またはグループの記憶ページで設定できます。

16. ElevenLabsのプライベート音声を設定

キャラクターの読み上げ、試聴、音声クローンには自分のElevenLabsアカウントを使います。APIキー、プライベート音声、プランの利用枠はあなたのものです。ユーザーの音声文字起こしには咲きのプラットフォーム用STTキーを使い、個人の利用枠は消費しません。Voice IDはキャラクター広場へアップロードされません。

手順1：ElevenLabsに登録し、APIキーを作る

  1. ElevenLabsの紹介リンクから登録またはログインします。
  2. アカウント設定のAPI Keysを開き、新しいキーを作成します。
  3. Text to SpeechとVoices / Voice Cloningを許可します。個人のキーにSpeech-to-Textの権限は不要です。
  4. 作成したキーをすぐにコピーして安全に保管し、全文を他人へ送らないでください。

手順2：咲きにキーを暗号化して保存する

プロフィール → アカウント・通知設定 → ElevenLabsでキーを貼り付け、「保存／上書き」を選択します。保存後は設定状態と末尾4文字だけが表示され、全文は再表示されません。

手順3：キャラクターの声を作る

  1. 連絡先から記憶・キャラクター設定 → 音声設定を開きます。
  2. 音声名を入力し、1人だけが明瞭に話す20 MB以下の音声をアップロードします。
  3. その声を使用する権利、または話者本人の明確な許可があることを確認します。
  4. 「アップロードして音声を作成」を選びます。成功するとVoice IDが自動入力され、現在のキャラクターに保存されます。
  5. 試聴して確認します。以後のキャラクター音声は自分のElevenLabsプランの利用枠を消費します。

咲きは今回のサンプルを音声作成のためElevenLabsに転送し、サンプル自体を長期保存しません。現在のElevenLabsアカウントでアクセスできるVoice IDを手入力することもできます。他人のプライベート音声は、IDを知っているだけでは使えません。

よくある音声エラー

  • APIキーが無効・未設定：プロフィールで個人のElevenLabsキーを保存し直します。前後に空白を入れないでください。
  • 権限不足・IP許可リストで拒否：TTSと音声操作の権限を確認し、IP制限を使っている場合は許可範囲を更新します。
  • Voice IDが使えない：現在のアカウントの音声、またはアクセス可能な共有音声であることを確認します。
  • 利用枠不足・音声数の上限：プランと保存済み音声数を確認し、不要な音声の削除やプラン変更を検討します。

17. キャラクター広場

好きなキャラクターを検索し、お試しチャットをしたり、自分の連絡先に追加したりできます。自作キャラクターを公開する際は、手元の既存キャラクターから情報を読み込むこともできます。

投稿時に入力できる項目は、ID（重複は自動処理）、名前、別名、年齢（時間とともに増やさない設定も可能）、作品名（IP）、タグ、関係図、人物設定です。

詳細ページの下には同じ作者の他のキャラクターも表示されます。いいね、お気に入り登録、匿名コメントができます。

18. 掲示板

  1. 連絡先ページ右上のプラスから「掲示板生成」を選びます。
  2. テーマ、種類、レス数を設定します。複数の会話履歴を読み込んだり、過去の掲示板を選んで続きを作ったりできます。
  3. 生成言語と補足情報を設定して生成します。内容はストリーミングで少しずつ表示されます。
  4. 生成結果の掲示板ブロックコードをコピーしてチャットへ送ると、掲示板形式で表示されます。

19. エラーとサーキットブレーカー

まず現在の接続先とモデルを確認し、表示に応じてキー、残高、権限、通信状態を調べます。提供元の生のエラーではなく、翻訳された短い案内が表示される場合があります。

どのエラーが制限の対象になる？

呼び出し経路カウント対象のHTTPコード
Gemini直接接続の通常のモデル呼び出し400、403
ChatGPT、Claude、Grok、カスタム、および掲示板のストリーミング生成（Geminiを含む）400、401、402、403
以前のrelay互換経路を使う呼び出し401、402、403、525。現在の「カスタム」とは異なります。

この表はチャットや要約などの共通モデル呼び出しと、掲示板のストリーミング生成が対象です。画像生成、音声、ウェブ閲覧などには独自のエラー処理と制限があり、同じ番号でも同じ制限がかかるとは限りません。

カウント・待機・解除の仕組み

  1. ユーザー＋接続先＋同じエラーコードごとに別々にカウントします。1回目は警告です。
  2. 同じエラーの2回目で10分間のクールダウンに入り、その接続先の対象呼び出しを止めます。
  3. 待機後、カウントがリセットされる前に同じエラーが3回目に達すると、その接続先が無効化されます。アカウント全体が凍結されるわけではありません。
  4. 無効化されていない接続先では、呼び出しが成功するとカウントが消えます。最後のエラーから30分超が経過し、クールダウン中でなければ、次の確認時にもリセットされます。
  5. 無効化済みの接続先は、30分待つだけでも、キーを変えるだけでも復旧しません。設定を直して管理者に解除を依頼するか、正しく設定した別の接続先を使ってください。

よくあるエラーへの対処

400 · リクエストが不正
モデルID、API形式、入力の種類、パラメーターを確認します。カスタムでは特に提供元とプロトコルが一致しているかを確認してください。
401 · 認証失敗
AIサービスのエラーならAPIキーの正しさと有効性を確認します。咲きの画面でログイン期限切れと表示された場合は、咲きへログインし直します。
402 · 残高・課金の問題
提供元のAPI残高、プラン、課金状態を確認します。
403 · アクセス拒否
モデルの権限、アカウントや地域の制限、キーの権限、アクセス方針を確認します。モデル名の誤りだけが原因ではありません。
404 · モデルや接続先が見つからない
提供終了、利用権限の不足、APIアドレスの誤りを確認します。上記の共通処理では404をカウントしません。
429 · 頻度・利用枠の制限
同時実行数と送信頻度を減らし、利用枠と残高を確認します。上記の共通処理では429をカウントしません。
500 / 502 / 503 / 504 · 提供元の障害・タイムアウト
時間を置いて試すか、入力を短くし、速いモデルを使います。上記の致命的エラーには含まれません。咲きの503はサービス未設定や制限中の場合もあるため、表示文も確認してください。
524 / 525 · 中継先のタイムアウト・接続問題
接続サービスの状態を確認します。現在のカスタムではどちらもカウントせず、以前のrelay互換経路のみ525をカウントします。
空の返答・解析失敗・出力の途切れ・ストリーム中断
完全で有効な結果が返っていません。入力の長さとモデルの能力を確認して再試行します。途中の出力を生成完了とは扱わないでください。
記憶の同期・要約失敗
記憶用モデルと接続設定を確認して手動要約します。失敗後の返答には新しく整理するはずだった記憶が含まれない場合があります。表示内容を確認してください。

自発処理で致命的エラーや制限が発生すると、キャラクターの浅い眠りが有効になったり、グループの自発メッセージやタイムラインの自発投稿が無効になったりする場合があります。接続を修正した後、必要なスイッチを再び有効にしてください。

相談時は、機能名、接続先、モデル、エラーコード、発生時刻、機密情報を隠した画面を伝えてください。APIキー全文、パスワード、確認コードは送らないでください。解除後は短いメッセージを1件送って確認します。

20. PWAアプリとしてインストール

咲きをホーム画面に追加すると、通常のアプリのようにアイコンから開けます。ウェブサイトのPWA版なので、APKのダウンロードやアプリストアは不要です。

PWAでもチャットにはインターネット接続が必要です。追加されるのは入口だけで、新しいアカウントは作られません。今までのメールアドレスとパスワードを使ってください。

3ステップで追加

  1. スマートフォンのブラウザーで咲きのホームページを開き、読み込みを待ちます。
  2. Androidではメニュー、iPhoneのSafariでは共有を開きます。
  3. 「アプリをインストール」または「ホーム画面に追加」を選んで確認し、ホーム画面の咲きアイコンを探します。

Android · Chrome

  1. Chromeで咲きを開きます。
  2. アドレスバー横または右上の「⋮」を選びます。
  3. 「ホーム画面に追加 → インストール」を選びます。版によっては「アプリをインストール」と表示されます。
  4. 案内に従って確定し、ホーム画面へ戻ります。

Android · Firefox（推奨）

  1. Firefoxで咲きを開きます。
  2. ブラウザーのメニューを開きます。
  3. 「インストール」を選びます。「ホーム画面に追加」だけの場合はそれを選べます。
  4. 「自動的に追加」を選ぶか、案内に従ってアイコンをホーム画面へ移動します。

iPhone / iPad · Safari

  1. Safariで咲きを開きます。
  2. 上向き矢印付きの四角い共有ボタンを選びます。配置によっては「その他」から共有を開きます。
  3. 下へスクロールして「ホーム画面に追加」を選びます。
  4. 「Webアプリとして開く」があれば有効にし、「追加」を選びます。

その他のAndroidブラウザー

  1. サイトを開き、3点または3本線のメニューを選びます。
  2. 「アプリをインストール」「デスクトップに追加」「ホーム画面に追加」などを探します。
  3. 名前とアイコンを確認して追加します。表記や位置はブラウザーごとに異なります。

追加の項目が見つからないとき

  • 「アプリをインストール」がない：「ホーム画面に追加」などを探し、読み込み後に更新するか、ブラウザーを更新してください。
  • iPhoneに「ホーム画面に追加」がない：Safariを使っているか確認し、共有メニュー下部の「アクションを編集」から追加します。
  • 追加後もアドレスバーが出る：ショートカットを追加した可能性があります。アイコンを削除してやり直し、インストールまたは「Webアプリとして開く」を選んでください。
  • オフラインで会話できない：正常な動作です。会話、同期、AIの返答には通信が必要です。

iPhone / iPadでプッシュ通知を受け取るには、ホーム画面に追加したアイコンから起動し、プロフィール → ブラウザー通知で許可してください。

21. アカウントと利用上の安全

通常の会話体験を変えずに、アカウントや利用時間を管理するための機能です。

アカウント開設の年齢条件

咲きは18歳以上の方が利用できます。管理者にアカウント開設を申し込む前に、年齢条件を満たしていることをご確認ください。

連続利用2時間のリマインダー

2時間を超えて連続利用すると、休憩を促す案内が表示されます。強制ログアウト、会話の停止、AIの返答への制限はありません。

安全に関する案内

会話に明確な身体の安全への危険が見られる場合、メッセージ付近に灰色の案内が中央表示されることがあります。身近な信頼できる人や地域の緊急窓口への連絡を促します。中国では全国心理支援ホットライン12356も案内されます。

案内は専門家の支援の代わりにはなりません。あなたや周囲の人に差し迫った危険がある場合は、身近な信頼できる人や地域の緊急窓口への連絡を優先してください。

アカウントを削除する

プロフィール最下部の「アカウント削除」を選び、影響の説明を読んで進みます。現在のパスワードと、画面で指定された確認フレーズを手入力して送信します。

  • 削除対象：アカウント、個人設定、非公開の会話とメディア、お試しチャット、あなたに紐づくコメントや利用記録を整理します。必要な内容は先に保存してください。
  • 公開投稿：公開キャラクターとスタンプパックは残り、作者アカウント、メール、元キャラクターとの関連を取り除きます。本文に書いた情報、作者を特定できない古いコメント、他者の保存済みコピー、第三者の記録は自動削除されません。投稿を消したい場合はアカウント削除前に対応してください。
  • 復元：削除済みデータは復元できません。クラウド側の整理に失敗した場合は、表示に従って再試行できます。
  • パスワードが違う場合：削除は実行されません。パスワードと確認フレーズの両方が正しい必要があります。
